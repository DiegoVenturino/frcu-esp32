# Tecnologías para la Automatización (ESP32)

This repository contains materials and practical exercises for working with the **ESP32** microcontroller, part of the **Ingeniería en Sistemas** program at UTN FRCU.
The main goal of this repository is to introduce students to embedded systems programming and simulation using the **[Arduino IDE](https://www.arduino.cc/en/software)** and **[Wokwi](https://wokwi.com/)**, an online simulator for ESP32, Arduino, and other microcontrollers.

---

## 🛠️ Installation

To set up your environment for ESP32 development:

1. Install the [Arduino IDE](https://www.arduino.cc/en/software).
2. Add ESP32 board support following the [official guide](https://github.com/espressif/arduino-esp32#installation-instructions).
3. (Optional) Create a free account on [Wokwi](https://wokwi.com/) to simulate circuits without physical hardware.

## 🎯 Objectives

By the end of this course, students should be able to:

- Understand the fundamentals of the ESP32 architecture and GPIO usage.
- Program basic firmware using the Arduino IDE.
- Simulate and validate circuits using Wokwi before deploying to real hardware.
- Apply embedded programming to solve simple real-world problems.
